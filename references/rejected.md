# What Harper rejected, and why

Patterns, with the real text where it could be recovered. Marked "illustrative" where the original text is gone. Never reuse these lines.

## 1. The same skeleton in every script
Six earlier drafts shared one skeleton: a hook, "Here's how it works." / "Here's why.", "But here's the trick.", and a last line starting "So essentially,". Harper's approved scripts don't share a skeleton; each is built around its own idea. If the draft you just wrote could be reached by swapping nouns in a previous one, rewrite it.
> *But here's the trick.* / *So essentially, it doesn't run out of fuel. It just slowly cools down.* (a Voyager draft)

## 2. A forced signpost that only announces more setup
Harper flagged "But here's the trick." in the Sun-light script: it sat before one more line of setup, not before the turn.
> *Inside this star, the gas is too dense for light to fly straight. / A photon moves less than a millimetre before an atom swallows it. / But here's the trick. / That atom spits it back out in a random direction.* (a Sun-light draft)
A signpost is fine when the very next line is the answer or the real turn. Test: delete it. If nothing is lost, delete it.

## 3. A hook that is a phone comparison
Harper rejected the phone-battery opening for Voyager and asked for a different style.
> *After five years, your phone's battery is worn out.* (a Voyager draft)
Line 1 should be the extreme thing itself, not the viewer's gadget set beside it.

## 4. Line 2 contradicting line 1
A Voyager hook said there was "no way to recharge" and then, a line later, that it was "making its own electricity". Illustrative (original text not recovered): each line must follow from the last without undoing it.

## 5. Decoration and synonyms for one thing
Harper rejected "glowing lumps" for plutonium. Name each thing plainly and keep calling it that: plutonium stays plutonium, not "the fuel", "the source", "the heart of the probe". (Original draft text not recovered.)

## 6. Going around the point
Harper called a batch of drafts "vague, trying to get to the point by going around": a scene-setter before the claim, a line that gestures at the idea without saying it. Line 1 hits. Illustrative: *"Far from home, a small machine keeps going."*

## 7. The writerly checker-passer
Colon fragments, wordplay hooks, the answer given away early, lines written to satisfy the checker, and trivia that adds nothing. Harper rewrote one such Raptor script from scratch. Plain spoken sentences, one question, the answer withheld.

## 8. The ten-year-old test
Explained to a ten-year-old, told as a story: each line follows from the last, a new thing in every line, the explaining itself keeps them watching. If a line needs a term the viewer hasn't met, say what it is in the same breath or cut it.
